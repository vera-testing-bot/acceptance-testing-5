# Example specification

A stub so an acceptance shard repo has a `docs/spec/` tree for the spec-driven
parts of the lifecycle to point at. The suite writes its own criteria when a
test needs them; nothing here is authoritative.

## Addition

The `add` helper returns the sum of its two arguments.

Done when:

- [x] `add(2, 3)` returns `5`.

## Subtraction

The `subtract` helper returns the difference of its two arguments.

Done when:

- [x] `subtract(5, 3)` returns `2`.
